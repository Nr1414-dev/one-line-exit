Entry for [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1)
bounty on make.fun: one resignation letter, exactly one line long, written
to `/output/entry.txt` by `main.py`.

The line:

> I hereby resign — from now on, please fasten your own seatbelts: I'm taking the emergency exit.

It was picked from eight candidates scored against the judge brief's criteria
in order — a funny one-line resignation letter, a surprise turn, fits the form,
a specific voice, and quotable. It won the 1v1 against the runner-up lines, and
it avoids the field's angles (IT reboot, open ticket, toner, office plant,
generic "Dear Manager" formal letters).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
